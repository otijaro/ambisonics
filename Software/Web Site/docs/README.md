# Índice de Documentación Técnica

Bienvenido a la documentación técnica del proyecto **Ambisonic**. Este repositorio de documentación está diseñado para proporcionar una comprensión profunda de la arquitectura, tecnologías y el flujo de trabajo tanto del Frontend como del Backend y del Procesamiento Digital de Señales (DSP) implementado en el proyecto.

A continuación, encontrarás el índice de los documentos disponibles:

- [00. Introducción](./00_Introduccion.md)
  Objetivo del proyecto, problema que resuelve, tecnologías utilizadas y arquitectura general.
- [01. Arquitectura](./01_Arquitectura.md)
  Estructura de directorios del proyecto y responsabilidades de cada carpeta.
- [02. Frontend](./02_Frontend.md)
  Análisis detallado de Next.js, App Router, estructura de páginas y lógica del lado del cliente.
- [03. Backend](./03_Backend.md)
  Documentación sobre FastAPI, el servidor Python y el flujo de los scripts de conversión.
- [04. Procesamiento Digital de Señales (DSP)](./04_DSP.md)
  Lógica matemática y de procesamiento de audio: FOA, binaural, HRTF y algoritmos.
- [05. Referencia de la API](./05_API.md)
  Endpoints expuestos por el backend, parámetros esperados y respuestas JSON.
- [06. Visualización 3D (Demo)](./06_Demo3D.md)
  Funcionamiento de React Three Fiber, Three.js, la representación del oyente y la fuente sonora.
- [07. Componentes de UI](./07_Componentes.md)
  Inventario y propósito de los componentes clave de React utilizados en la interfaz.
- [08. Despliegue (Deployment)](./08_Deployment.md)
  Guía de ejecución local y comandos para desplegar el Frontend (Vercel) y el Backend (Railway).
- [09. README General](./09_README.md)
  Versión sugerida para el `README.md` público del repositorio de GitHub.
